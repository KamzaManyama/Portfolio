03

Academic group project · Live

Cape Town Food Insecurity Screening

A screening tool that estimates whether a Cape Town household is at risk of adult hunger, built as a group project for IDA117V using the City of Cape Town Household Survey 2024.

The problem
Outreach teams need to know which households and areas to prioritise. The tool turns a short household profile into a screening score, a flag and an explanation.
What we built
A 9-question quick screen and a full form, CSV batch scoring, and a lookup across 162 surveyed suburbs, all running a tuned MLP pipeline that finds 84% of at-risk households on the test set (ROC-AUC 0.848).

Python · Machine learning · Docker
