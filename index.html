About

I'm Maredi, a software developer from Midrand who likes taking real problems and turning them into software people can actually use.

I work at Mphoti Consulting, a consultancy that places me with its clients. I joined as an intern in 2024 and became a full-time junior developer in 2025. I'm also completing an Advanced Diploma in Computer Science at Tshwane University of Technology.

Through Mphoti I've built features for high-traffic betting platforms at Sunbet and PantherBet, and automated end-to-end testing with Playwright at e4. Having worked on both sides, I care as much about whether software holds up as about how it gets built.

I also build complete products end to end, like Invoice Ingest, an invoice management system with South African VAT built in. I work mainly with JavaScript, React and Node.js, and I enjoy the whole path from the first idea to a working product.

Right now I'm learning React Native, accessibility and performance testing. Longer term, I want to build and own a South African tech product that measurably improves people's lives.

01

Concept build

Invoice Ingest

A full-stack invoice management system built for a working client, live as Invoq. It ingests supplier invoices from CSV files, validates South African VAT rules and removes duplicates.

3
User roles
15%
VAT applied automatically
Market relevance
Addresses a real operational pain point for South African SMEs and finance teams: manual, error-prone invoice reconciliation. It has compliance with local VAT rules built in, a gap most generic invoicing tools don't cover.
Why I built it
I wanted a full-stack project that went beyond CRUD and forced me to work with real business rules: South African VAT logic, deduplication and automated notifications, the kind of constraints I'd face on a client engagement.
What it covers
CSV invoice ingestion, VAT validation, duplicate removal, multi-user approval workflows, MySQL storage and Gmail alerts after each run.

Node.js · Express · MySQL · Gmail API · Tailwind CSS
